# 🎬 Netflix Content Analysis – Power BI

## 📊 Project Overview

This project analyzes the Netflix Titles dataset using **Power BI** to understand Netflix's content library, including movies, TV shows, genres, countries, release years, ratings, and content trends.

The dashboard provides interactive visualizations that help identify patterns and insights in Netflix's content.

---

## 🎯 Objectives

- Analyze the distribution of Movies and TV Shows
- Identify the most common content ratings
- Analyze Netflix content by release year
- Explore content distribution across countries
- Identify popular genres and categories
- Understand how Netflix's content library has evolved over time
- Create an interactive dashboard for data-driven insights

---

## 🗂️ Dataset

The project uses the **Netflix Titles Dataset** containing information about Netflix movies and TV shows.

### Dataset Details

- **Total Records:** 8,807
- **Content Types:** Movies and TV Shows
- **Key Columns:**
  - `show_id`
  - `type`
  - `title`
  - `director`
  - `cast`
  - `country`
  - `date_added`
  - `release_year`
  - `rating`
  - `duration`
  - `listed_in`
  - `description`
